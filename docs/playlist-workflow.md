# 两端歌单编辑与年度榜单

## 页面使用

- QQ、网易云共用一张歌曲列表。每行右侧显示时长、编辑按钮和三横线拖拽手柄，不再显示一份单独的编辑列表。
- 按住三横线可用鼠标或触屏拖动到目标位置，靠近浏览器上下边缘会自动滚动，松手后提交一次完整排序。键盘可用空格选中手柄、方向键移动、回车保存、Escape 取消。搜索过滤时关闭排序，避免隐藏歌曲位置不明确。
- 点击行内编辑按钮可从平台歌单移除该歌曲；添加歌曲从工具栏进入。搜索框左侧固定显示“歌单编辑结果会同步对应音乐平台”。
- “歌单资料”支持改名，以及从当前歌单中选择一首歌的专辑封面作为歌单封面。本次不支持上传任意本地图片。
- QQ 修改资料使用已核对的 `EditPlaylist`、`mask:95`，保留刚读回的描述、标签、另一张封面及隐私设置；网易云仅调用名称专用更新接口，并将选中的平台专辑封面经 SDK 上传为新的歌单封面。两端均核对归属、快照及写后资料。
- QQ 时长来自平台 `interval`（秒），网易云来自 `dt`（毫秒）并转换为秒；平台缺失时显示“—”，不估算时长。

## 歌单保存为年度榜单

在歌单工具栏选择“保存年度榜单”，填写名称、年份，选择年度单曲榜／年度专辑榜，以及评分／不评分。保存会新建一份 `yearlyRankings` 历史记录，不覆盖已有历史，也不立即替换当前未保存的榜单。用户点击“打开榜单”后才进入该记录。

单曲榜沿用完整平台歌单顺序；专辑榜映射每首歌所在的专辑，同专辑按平台专辑 ID 去重，保留第一次出现的顺序。若专辑名缺失则提示刷新或选择单曲榜，不生成缺项榜单。与搜索过滤无关，始终转换完整歌单。

所有评分字段（原始分、加分、最终分）初始均为 0。打开记录时还原评分模式、顺序及年份，避免自动重新排序或把相同的 0 分映射为 10 分。

## 站内播放是否会计入音乐平台

当前站内播放器未接入 QQ／网易云的播放行为上报链路。获取音源地址、播放 CDN 音频，不能视为已向平台提交有效收听记录，因此不保证计入最近播放、个人听歌时长、等级或年度报告。平台是否依据其他网络请求作统计，也不能由本项目确认。

本地 QQ 服务没有播放记录上报路由。网易云已安装的 SDK 包含 `scrobble`，其实现请求 `feedback/weblog`，但 MeloRank 后端没有挂载它，播放器也没有调用。若以后接入，需要根据真实播放进度处理暂停、跳转、试听、切歌和账号变更，并实际验证平台是否接受，不能只在点击播放时虚报完整收听。

## 仓库可用接口

完整逐项清单见 [接口清单](platform-api-inventory.md)。该清单区分本网站已挂载的路由与 SDK 存在但尚未挂载的模块。

| 范围 | 当前主要能力 |
| --- | --- |
| QQ 本地服务（40 条路由） | 扫码登录／账号、歌曲搜索与联想／热词、歌曲及专辑信息、歌手资料／专辑／热门歌曲／MV、推荐／榜单／电台、歌词／评论、音源／MV 播放地址、个人曲库，以及歌单增删／排序／名称／封面更新 |
| 网易云网站后端（12 条 POST 路由） | Go 扫码会话与轮询、账号／退出、歌曲搜索／联想／专辑搜索、播放地址／歌词、个人曲库／歌单或专辑详情、歌单增删／排序／名称／封面更新 |
| 网易云完整 SDK（449 个模块） | 登录和用户、搜索、歌曲及音源、歌单编辑、专辑／歌手、MV／视频、评论／动态、收藏、推荐／私人 FM、电台／播客、云盘、历史和播放上报等；大多数尚未接入本网站 |

## 验证和限制

运行 `npm run check:playlist`、`npm run check:ranking`、`node scripts/check-platform-library.cjs`、`npm run typecheck` 和 `npm run build`。测试使用隔离模拟账号及存储，不修改真实私人歌单。

浏览器连接服务不可用，因此实际字体、尺寸、对齐、鼠标／触屏拖拽与平台实号读回仍需页面联调确认。模拟接口成功不能替代真实平台写入验收。
