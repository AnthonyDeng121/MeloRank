# 新专辑／EP 发现

从「新碟发现」进入。第一版使用 QQ 音乐新碟列表，支持近七天、近三十天、类型和风格筛选。打开「选曲试听」后可换曲，站内播放器使用平台允许的音源或试听片段。试听满意后标记「想听」，再批量收藏整张发行；也可跳过和撤销。收藏和手动分类存于当前浏览器。可以补录 QQ 音乐专辑链接、隐藏艺人栏相同的发行，并撤销屏蔽。

## 数据与分类

- 将发行发现、元数据补全和播放来源分开。QQ 音乐提供第一批候选；后续验证其他平台、唱片目录和编辑来源的接口、授权、覆盖与维护成本。歌词站主要用于资料补全。
- 保存各来源的作品 ID、原始发行日期、来源链接及采集时间，展示覆盖范围和最近更新时间。用手动补录弥补漏收。
- 建立跨平台作品 ID，再关联地区版、豪华版、再版和平台 ID。优先使用可靠标识和来源证据，只有名称相似时留待确认。当前仅按平台和 ID 去重。
- 正式分类分成发行形式（专辑、EP、单曲）、作品属性（原声、精选、现场、混音）、版本（标准、豪华、再版）和可多选风格。第一版合用一个类型筛选，标题规则只给出可改的初始标签，未知保留，不按曲目数量判断 EP。
- 风格偏好支持优先查看与排除。缺少风格时仍可纳入浏览。小众作品保留探索位置。

## 推荐与试听

- 兴趣匹配与关注证据分别展示。用关注艺人、风格、历史收藏和跳过辅助排序；用编辑收录、多个独立来源和后续评价说明推荐原因。
- 新发行的评分人数和播放量只作辅助信号。数据少代表不确定，不能直接当作低质量。积累到足够数据后，可对评分做保守加权；不同平台的分数需校准。
- AI 艺人筛选优先采用可追溯的公开标注。异常发行频率可以作为待核查信号，不能据此直接判定。保留个人屏蔽入口和未知状态。
- 试听可优先推荐一首平台有音源的曲目，显示曲名和音源状态，同时允许换首。继续改进按周处理进度、稍后再听和跨设备续看。
- 整张专辑收藏与收藏曲目或写入歌单是不同操作。当前存在 MeloRank 本地收藏，后续验证各平台的专辑写入能力、授权、失败提示和幂等重试。
